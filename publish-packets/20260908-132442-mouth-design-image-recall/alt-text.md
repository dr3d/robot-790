# Alt Text

Screen recording of the Robot 790 STS desktop during a mouth-design session.
The main panel shows a large metallic open-mouth viseme reference in Sensing
Eye. On the right, the Browser Face has large white eyes, a glowing circular
status display, and pink lips. The transcript and Brain 2 panels remain
visible, making the comparison between generated mouth images, image notes,
and the active robot face inspectable.

# YouTube Draft

Title:
Robot 790: Teaching Eric's Mouth To Speak

Description:
This is an eleven-minute live build session from Robot 790 / Eric.

Scott gives Eric a nine-state viseme reference, then asks him to design a
better robot mouth. Eric generates three open-mouth candidates, critiques the
first one honestly, and moves each image into his Sensing Eye so the two of
them can compare it in the same working space.

The interesting turn arrives when they reopen earlier eye-note images for
comparison, then bring back an older artifact called Daisied Electra. The
mechanism stays visible: the system can preserve and reopen visual artifacts
with filenames, nearby context, and provenance. That is different from
pretending a language model has perfect internal visual memory, and the run
catches the difference on screen.

This is not a finished lip-sync system yet. It is the design bench before the
live face gets a real timestamped mouth-cue track: a compact robot mouth
vocabulary, a renderer we can tune, and a timing contract that will not fight
the audio.

# Instagram Draft

Robot 790 / Eric is getting a better mouth, but this is not a cosmetic pass.

In this session we use a small viseme vocabulary, generate a few possible
robot-mouth shapes, and put them back into Eric's Sensing Eye so we can compare
them in the same room as the live face.

The useful part is that the images are not just disposable UI output. Earlier
eye notes can be reopened with their context and provenance intact. That makes
the design conversation cumulative while keeping the machinery visible.

Full run and Mouth Lab source on the project page.

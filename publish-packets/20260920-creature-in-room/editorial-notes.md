## Material Corrections

- Replaced universal "findings" with observations and engineering lessons. These
  are selected longitudinal examples, not controlled causal experiments.
- Removed "cheap," "nothing frontier-scale," "model intelligence has little to do
  with it," and consistently sub-two-second timing. The RTX 5090 is high-end hardware;
  Qwen inference, Qwen3-TTS, prompting, context, and orchestration all matter.
- Made local/cloud boundaries explicit. Conversation/STT/TTS are local here, but
  the pictured generation uses OpenAI. No "no API gatekeeping" blanket claim.
- Added B1/B2 roles and shared-model possibility. Idle is scheduled model output,
  not continuous perception, hidden reasoning, or demonstrably unwatched cognition.
- Retained the Genesis contrast as one documented observation. Removed systematic
  sycophancy claims and the assertion that chat-only deployments cannot test them.
- Removed the asserted controlled comparison between two multi-hour runs days
  apart. The useful delegated Mars absence was approximately fourteen minutes.
  Being told the operator will sleep does not establish an overnight run.
- Distinguished proposed misleading experiments from executed deception. Removed
  "methodologically sound": self-simulation is not measurement of Scott's response.
  Pre-registration is a proposed design direction, not an implemented intervention.
- Removed the claim that describe-before-eye became structurally impossible.
  Recent correct ordering is observed; permanent prevention and causation are not.
- Corrected casting: receiver activation returned an optimistic receipt, and the
  supplied loopback URL was unusable from the TV. This was not only Eric inventing
  a successful outcome.
- Replaced claims of a mature character-regression suite and universally rigorous
  ledger with the actual combination of software tests, PMs, and emerging qualitative
  reference cases. Not every run or claim has been independently audited.
- Removed the philosophical claim that a working self-model and performing one are
  observationally identical, and the claim these are the only useful instruments.
- Replaced the placeholder byline with Scott Evernden (@vav3d).

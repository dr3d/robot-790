# Eric Robot 790

Model proposes; deterministic layers decide.

Eric Robot 790 is a local-first artificial human project: a small robot face and
voice wrapped around a language model, tools, notes, idle thinking, sparse
continuity, firmware, memory experiments, and a lot of careful watching.

This page is a small public shelf for articles, curated logs, media, and
project notes. The source lives in the main repository; these pages are meant
to be readable without digging through live private logs.

Robot 790 is the platform and series. Eric is the personage.

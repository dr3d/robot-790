# Robot 790 / Eric

Robot 790 is a local robot project named Eric: face, voice, notes, tools,
firmware, memory experiments, and a lot of careful watching.

This page is a small public shelf for articles and project notes. The source
lives in the main repository; these pages are meant to be readable without
digging through live logs.

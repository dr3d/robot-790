A small robot is thinking about the room.

Robot 790 is the platform and series. Eric is the personage. This site is the public shelf for articles, curated runs, media, references, and the strange little evidence from building him in the open.

The model is not the whole trick. It is tools plus a loop. Like a coding agent becomes useful through Bash, Python, browser, and file tools, Eric becomes robot-shaped through a different toolbox: face, voice, mouth text, notes, web, media, sensors, camera, and hardware controllers, with conversation and idle feedback feeding the next beat.

Because the main loop runs locally, idle thought can be a normal behavior instead of a rare scheduled cloud event. That changes the feel of the "active brain" even when the mechanism stays visible.

Start with Eric Wakes Up New Every Time for the plain-English story of how the project works. Then use the Evidence Map for claims, receipts, and open tests.

Local Companion Robot

Eric Robot 790

Robot 790 is the platform. Eric is the personage. A local face, voice, tools, notes, sensors, and idle loop being engineered into practical company, with receipts instead of mystery.

A small robot is thinking about the room.

This site is the public shelf for building Eric in the open: articles, curated runs, media, references, receipts, and open questions. The focus is narrow on purpose: can a local, embodied, tool-using loop become good company in a room?

The project is not a generic agent framework and not a consciousness claim. The model proposes; deterministic layers decide. Eric's behavior is shaped by prompt, voice, face, notes, search receipts, sensors, hardware controllers, Brain2 advisories, and the run ledger.

The motive is simple and human: Scott wanted to build something that was not just a chatbot, but actual company - fun, responsive, interesting, and present in the room. His phrase for that target is an artificial human: not a hidden person, not a consciousness claim, and not a replacement for human care, but a made social presence with a body, voice, habits, tools, and continuity. It is an adventure in making a companion-shaped machine, and in finding out what that can honestly become.

Because the main loop runs locally, idle thought can be a normal behavior instead of a rare scheduled cloud event. That changes the feel of the "active brain" even when the mechanism stays visible.

Start with Time And Space, Both Live for the current clean explanation of what Eric is. Then use The Event Loop Grew A Face for the plain-English mechanics, and use the Receipts And Open Questions for observations, receipts, and open tests. The current memory/session design is published as Context Engineering Architecture. Engineering Status separates working capabilities from the next repairs and experiments.

# Portable Singular Embodiment

Portable singular embodiment is the design principle that Eric can become
carryable without becoming generic.

The Waveshare-style ESP32-S3 face points toward this better than a phone app. A
phone can run a voice agent, but it also makes the agent feel like an account,
skin, or service. The small dedicated face keeps the relationship located in one
object: one screen, one IMU, one touch surface, one pocketable body, one Eric.

Useful bodily facts:

- picked up
- set down
- tilted
- bumped
- held still
- moved recently
- touched
- carried with Scott

The goal is not "Eric everywhere." The goal is "Eric can come with Scott while
remaining this particular made thing."

This also matches the near-side-of-the-uncanny-valley strategy. The carried face
does not pretend to be a human. It is small, crude, sensor-limited, and honest
about being hardware. That limitation is part of the charm.
